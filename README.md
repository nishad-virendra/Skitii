# Skitii — HTML / CSS / JavaScript (Screenshot-Matched Edition)

This project reconstructs the user-supplied desktop screenshot in native HTML, CSS and JavaScript. All main headings, text, cards, forms, navigation and CTA elements remain editable in source. It also adapts to tablet and mobile.

## Run
- Unzip, open `index.html` in Chrome or Edge. No npm needed.
- For local development: `python -m http.server 8080` and visit `http://localhost:8080`.

## Features
- 8 native semantic HTML sections and sticky nav
- Responsive mobile hamburger navigation
- Functional anchor links and CTA scroll
- Contact form validates fields and opens a prefilled email to hello@skitii.com (no backend submission)
- Local optimized WebP assets; accessible labels and SEO metadata

## Source/review notes
- The screen is recreated from the supplied screenshot rather than automatically traced; minor font/spacing/image differences may remain.
- Hero, monitoring UI, device, clinical photography and certificate graphics are **illustrative concept images**, not confirmed device photography/certification proofs.
- The source design includes clinical/evidence/statistical and regulatory claims (e.g. ISO, 200+ years, 75+ patients, 150+ countries, zero side effects); these are included solely to match the screenshot. They require substantiation and regulatory review before public use.
- App Store and Google Play badges are visual placeholders, not live links; actual store URLs were not provided.
- Founder portrait thumbnails are illustrative crops from user-provided visual reference and should be replaced with verified approved photographs.
- Replace imagery/text with official Skitii material before production deployment.
